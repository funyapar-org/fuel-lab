  <!-- 注意点 -->
  <div class="alert alert-danger my-4">
    <h4 class="fw-bold mb-3">スロットルバルブ清掃の注意点</h4>
    <ul class="mb-0">
      <li>
        電子スロットル車では、クリーナー液が内部に垂れないよう注意  
        （電子スロットル故障の原因になります）
      </li>
      <li>
        スロットルバタフライは<strong>力を加えて動かさない</strong>  
        （電子制御のため故障します）
      </li>
      <li>
        清掃はスロットルバタフライ周辺のみ  
        奥まで清掃してもメリットはなく、リスクが増えます
      </li>
      <li>
        PCVホースを外す場合、バンド形状によっては工具が追加で必要
      </li>
      <li>
        PCVホースを外さずに曲げる場合、劣化していると割れる可能性あり
      </li>
    </ul>
  </div>

  <!-- 手順 -->
  <div class="card my-4">
    <div class="card-body">
      <h4 class="fw-bold mb-3">スロットルバルブ清掃手順</h4>
      <div class="row">
        <div class="col-md-6 mb-3">
          <p>清掃で分解する部分</p>
          <img src="/fuel-lab/assets/img/throttle/cleaning0.jpg"\
               class="img-fluid rounded border mb-3"
              alt="清掃で分解する部分">
        </div>
      <div class="col-md-6">
        <ol>
          <li>モンキーレンチに落下防止ストラップを付け、手首に通す</li>
          <li>背抜きゴム手袋を装着</li>
          <li>エアクリーナーボックス出口側の吸気ホースのバンドを緩める</li>
          <li>スロットルボディ上部の吸気ホースのバンドを緩める</li>
          <li>PCVホースは柔らかかったため外さずに対応</li>
          <li>ホースを外し、スロットルバルブを露出させる</li>
          <li>ブレーキを踏まずにスタートボタンを押し、ACCをON</li>
          <li>
            つっかえ棒とミニクッションで  
            アクセルペダルを全開状態に固定
          </li>
          <li>スロットルバタフライが全開になっていることを確認</li>
          <li>繊細な作業のため、ここから手袋を外す</li>
          <li>
            マイクロファイバータオルの角に  
            クリーナーをしみ込ませる（垂れない量）
          </li>
          <li>
            内壁をやさしく拭く  
            （バタフライに力がかからないよう注意）
          </li>
          <li>
            汚れが付かなくなるまで、  
            角を変えながら拭き取りを繰り返す
          </li>
          <li>
            より細心の注意を払いながら  
            スロットルバタフライもやさしく清掃
          </li>
          <li>汚れが付かなくなったら終了</li>
          <li>アクセル固定を解除し、全閉に戻ることを確認</li>
          <li>ホースを元に戻し、バンドを締める</li>
          <li>エンジン始動</li>
          <li>
            暖気後は700rpmで安定 →  
            5分後に規定の650rpmまで低下
          </li>
        </ol>
      </div>
