# fuel-lab
ガソリン車の燃費研究所

------------プロンプト------------
【前提】
ガソリン車の燃費改善をテーマにしたサイトを作成中です。
燃費改善のアドバイスをするためのツールやシミュレーターを用意しています。
各ツールで出た結果を見たことで最終的にはアフェリエイトリンクを踏んでfcr062とかを買ってほしいのですが、説得力を持たせるためいくつか車の知識に関するページを作りたいと思います。

【達成すべき課題】
私のソリオメンテナンス日記を投稿するためのテンプレートを作成してほしい。
「ソリオの日記」のページに入ると日記を最新のものからカード形式で列挙してほしい。
一度に読み込むのは１０件ほどで下までスクロールすると追加で１０件読み込むような挙動にしてほしい。
できれば年月のアーカイブリンクでその年のその月の記事がまとめて見れたりすると、なお良し。
あとは日記を検索する機能もあってもいいかも。

【出力形式の補足】
github pages でjekyllを使用しています。
default.htmlである程度共通化が進んでいます。
共通部分でbootstrap v5.3を読み込んでいるのでいい感じの見た目に整えてください。
「##」などのmd固有の見出し表現は使わないでください。
関連ページのリンクがあると嬉しいです。
コピペしたいので各ファイルは全文でください。
