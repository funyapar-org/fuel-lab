  <h1 class="mb-4">{{ page.title }}</h1>

  <p class="lead">
    「燃費を良くしたいけど、何からやればいいかわからない」  
    そんな方に向けて、<strong>効果が大きい順にやるべきこと</strong>を整理しました。
  </p>

  <div class="alert alert-success">
    結論：<br>
    <strong>①運転 → ②空気圧 → ③短距離対策</strong><br>
    まずはこの3つだけでOKです
  </div>

  <hr class="my-5">

  <!-- 優先順位 -->
  <h2 class="mb-4">最初にやるべき3つ（効果が大きい順）</h2>

  <div class="list-group mb-4">

    <div class="list-group-item">
      <h5>① 運転方法を見直す（最重要）</h5>
      <p class="mb-1">
        燃費に最も影響するのは運転です。
      </p>
      <ul class="mb-2">
        <li>急加速をやめる</li>
        <li>一定速度を意識する</li>
        <li>早めにアクセルオフ</li>
      </ul>
      <p class="mb-0">
        → <strong>5〜20%レベルで変わることもある</strong>
      </p>
    </div>

    <div class="list-group-item">
      <h5>② タイヤの空気圧を適正にする</h5>
      <p class="mb-1">
        空気圧不足は「常に燃費が悪い状態」になります。
      </p>
      <ul class="mb-2">
        <li>月1回チェック</li>
        <li>指定値〜+10kPaが目安</li>
      </ul>
      <p class="mb-0">
        → <strong>1〜3%改善（コストほぼゼロ）</strong>
      </p>
      <p class="mt-2 mb-0">
        <a href="{{ site.baseurl }}/knowledge/tire-air-pressure/">詳しくはこちら</a>
      </p>
    </div>

    <div class="list-group-item">
      <h5>③ 短距離運転を減らす</h5>
      <p class="mb-1">
        燃費悪化の最大要因のひとつです。
      </p>
      <ul class="mb-2">
        <li>暖機前に走行終了</li>
        <li>エアコン負荷が相対的に増大</li>
      </ul>
      <p class="mb-0">
        → <strong>気づかないうちに大きく燃費を落とす</strong>
      </p>
    </div>

  </div>

  <hr class="my-5">

  <!-- 次のステップ -->
  <h2 class="mb-4">次にやると効果が出やすいこと</h2>

  <ul class="list-group mb-4">
    <li class="list-group-item">
      <strong>エアコンの使い方を見直す</strong><br>
      A/Cの使い方で5〜20%変わることもあります。<br>
      <a href="{{ site.baseurl }}/knowledge/air-conditioner-fuel-economy-impact/">詳しくはこちら</a>
    </li>
    <li class="list-group-item">
      <strong>不要な荷物を降ろす</strong><br>
      影響は小さいが積み重なると差になる
    </li>
    <li class="list-group-item">
      <strong>渋滞の少ないルートを選ぶ</strong><br>
      停止回数を減らすだけで燃費は改善
    </li>
  </ul>

  <hr class="my-5">

  <!-- メンテ -->
  <h2 class="mb-4">メンテナンス系（中長期で効く）</h2>

  <ul class="list-group mb-4">
    <li class="list-group-item">
      <strong>エンジンオイル交換</strong><br>
      劣化すると確実に燃費悪化
      <br><a href="{{ site.baseurl }}/knowledge/engine-oil-interval/">交換目安はこちら</a>
    </li>
    <li class="list-group-item">
      <strong>エアフィルター</strong><br>
      吸気効率に直結
    </li>
    <li class="list-group-item">
      <strong>点火系（プラグ）</strong><br>
      燃焼効率に影響
    </li>
  </ul>

  <hr class="my-5">

  <!-- 添加剤 -->
  <h2 class="mb-4">補助的な手段（優先度は低め）</h2>

  <p>
    燃料添加剤などは「状態改善」には有効ですが、
    <strong>基本対策の後に検討するもの</strong>です。
  </p>

  <ul class="list-group mb-4">
    <li class="list-group-item">
      <a href="{{ site.baseurl }}/knowledge/fuel-additive/">
        燃料添加剤とは何か？
      </a>
    </li>
  </ul>

  <div class="alert alert-warning">
    まずは「運転・空気圧・使用環境」を整える方が効果は大きいです
  </div>

  <hr class="my-5">

  <!-- まとめ -->
  <h2 class="mb-4">まとめ</h2>

  <div class="alert alert-primary">
    <ul class="mb-0">
      <li>最優先は運転（最大効果）</li>
      <li>次に空気圧（コスパ最強）</li>
      <li>短距離運転が大きな悪化要因</li>
      <li>メンテナンスは土台</li>
    </ul>
