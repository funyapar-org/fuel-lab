<div class="container my-5">
  <h1 class="mb-4">{{ page.title }}</h1>

  <p class="lead">
    燃費はエンジンだけで決まるものではありません。  
    実は「タイヤ」と「ホイール」の選び方・状態・使い方が大きく影響します。  
    このページでは、燃費とタイヤ・ホイールの関係をわかりやすく解説します。
  </p>

  <hr class="my-4"/>

  <h2 class="mt-5">1. タイヤが燃費に影響する理由</h2>
  <p>
    車が走るとき、タイヤは常に道路と接しているため、  
    <strong>「転がり抵抗」</strong>と呼ばれる抵抗が生まれます。
  </p>

  <div class="alert alert-secondary">
    <strong>ポイント：</strong>  
    転がり抵抗が大きい = エンジンが強い力を出さないといけない = 燃費が悪化する
  </div>

  <p>
    タイヤの種類・空気圧・磨耗状態・硬さなどによって転がり抵抗は大きく変わります。  
    つまり、<strong>燃費を考えるならタイヤ管理は避けて通れない要素</strong>です。
  </p>

  <h2 class="mt-5">2. タイヤの消耗と燃費の関係</h2>
  <p>
    タイヤがすり減ると、性能は次のように変化します。
  </p>

  <ul class="list-group mb-4">
    <li class="list-group-item">
      <strong>摩耗 → ゴムが硬くなる</strong><br>
      ゴムは時間とともに硬化します。硬くなると転がり抵抗が増え、燃費が悪くなります。
    </li>
    <li class="list-group-item">
      <strong>摩耗 → 溝が浅くなる</strong><br>
      雨の日のグリップが低下して安全性が下がります。燃費より安全性が問題になる状態です。
    </li>
    <li class="list-group-item">
      <strong>寿命が近づく → 空気が抜けやすくなる</strong><br>
      空気圧が下がると転がり抵抗が大幅に増え、燃費は確実に悪化します。
    </li>
  </ul>

  <div class="alert alert-info">
    タイヤは「溝があるから使える」わけではありません。  
    製造から4〜5年でゴムが硬くなり始め、燃費にも悪影響が出てきます。
  </div>

  <h2 class="mt-5">3. 燃費を重視したタイヤの選び方</h2>

  <p>日本のタイヤには転がり抵抗性能を示すグレードがあります。</p>

  <ul class="list-group mb-4">
    <li class="list-group-item"><strong>AAA</strong> → 最も燃費が良い</li>
    <li class="list-group-item"><strong>AA</strong></li>
    <li class="list-group-item"><strong>A</strong> → 一般的に「エコタイヤ」</li>
    <li class="list-group-item"><strong>B</strong> → 標準的</li>
    <li class="list-group-item"><strong>C</strong> → 燃費は悪め</li>
  </ul>

  <p>
    燃費を重視するなら<strong>「A以上」</strong>がおすすめ。  
    特に街乗りが中心の人は、加減速が多いためエコタイヤの恩恵が大きく出ます。
  </p>

  <h2 class="mt-5">4. ホイールの重量と燃費の関係</h2>

  <p>
    ホイールは素材によって重さが大きく変わります。  
    ホイールが軽いほど燃費が良くなる理由は次の通りです。
  </p>

  <div class="alert alert-secondary">
    <strong>理由：</strong>  
    ホイールは「回転する質量」なので、重いほど加速に大きなエネルギーが必要になる。
  </div>

  <h4 class="mt-4">主なホイール素材の特徴</h4>

  <ul class="list-group mb-4">
    <li class="list-group-item">
      <strong>スチール（鉄）ホイール</strong>  
      <br>安いが重い。燃費では不利。
    </li>
    <li class="list-group-item">
      <strong>アルミホイール</strong>  
      <br>軽くて燃費が良い。扱いやすく一般的。
    </li>
    <li class="list-group-item">
      <strong>軽量アルミ / 鍛造ホイール</strong>  
      <br>非常に軽いので燃費面でも効果大。ただし高価。
    </li>
  </ul>

  <p>
    町中を走る車なら「一般的なアルミホイール」にするだけでも体感できる差があります。
  </p>

  <h2 class="mt-5">5. インチダウンは燃費に有利？不利？</h2>

  <p>
    インチダウンとは、ホイールの直径を小さくし、  
    その分タイヤの肉厚を増やすことを指します。（例：15インチ → 14インチ）
  </p>

  <div class="alert alert-info">
    <strong>基本的にはインチダウンすると燃費は良くなる傾向があります。</strong>
  </div>

  <p>理由は次の通りです：</p>

  <ul class="list-group mb-4">
    <li class="list-group-item">
      <strong>① ホイールが軽くなる</strong><br>
      小さいホイールほど軽くなるため、加速に必要なエネルギーが減る。
    </li>
    <li class="list-group-item">
      <strong>② タイヤの幅が狭くなることが多い</strong><br>
      接地面積が減り、転がり抵抗が小さくなる。
    </li>
    <li class="list-group-item">
      <strong>③ タイヤの肉厚が増える → 路面抵抗が減ることもある</strong><br>
      柔らかくクッション性があるため、燃費が向上するケースがある。
    </li>
  </ul>

  <p>
    ただし大型ミニバンや重い車でやりすぎると、  
    カーブでの安定性が落ちる場合もあるため注意が必要です。
  </p>

  <h2 class="mt-5">6. まとめ：タイヤとホイールは「燃費の鍵」</h2>

  <p>
    タイヤとホイールは、燃費に直結する数少ない「乗り心地以外の要素」です。
  </p>

  <ul class="list-group mb-4">
    <li class="list-group-item">タイヤが消耗すると燃費は悪化する</li>
    <li class="list-group-item">エコタイヤ（A以上）を選ぶと燃費改善が期待できる</li>
    <li class="list-group-item">軽いホイールは燃費に有利</li>
    <li class="list-group-item">インチダウンは燃費改善に効果的なことが多い</li>
  </ul>
